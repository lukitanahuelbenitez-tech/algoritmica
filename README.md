## Descripción

Este repositorio contiene el desarrollo de la Actividad 9 - "Pensar antes de programar".

El objetivo es aplicar conceptos fundamentales de programación mediante ejercicios desarrollados en C++, utilizando variables, constantes, estructuras condicionales, ciclos, estructuras (`struct`) y arreglos.

## Ejercicios realizados

1. **El Sensor de Aprobación:** cálculo del promedio de dos calificaciones y evaluación mediante una condición.
2. **Bucle del Contador de Vidas:** utilización de un ciclo while para controlar las vidas de un jugador.
3. **Registro de Jugador en Memoria:** declaración y utilización de una estructura struct.
4. **Control de Inventario con Arreglos:** recorrido de un arreglo para detectar posiciones sin stock.

## Tecnologías utilizadas

- Lenguaje C++.
- Visual Studio Code.
- Compilador G++.
